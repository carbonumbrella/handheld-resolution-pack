ClawTweaks Xbox Game Bar Widget Patcher
(Adds 1600x1000 and 1536x960 to ClawTweaks quick settings menu)

USAGE:
1. Double-click Run_As_Admin.cmd.
2. The script will locate XboxGamingBarHelper.exe, create a backup (XboxGamingBarHelper.exe.original.bak), and inject 1600x1000 and 1536x960 into the resolution whitelist.
3. ClawTweaks and Xbox Game Bar will automatically restart.

ROLLBACK:
- Run restore_clawtweaks.ps1 to restore the original binary from backup.
